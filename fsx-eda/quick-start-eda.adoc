= Quick start for Workload Factory for EDA
:icons: font
:imagesdir: ../media/

[.lead]
Get started with Workload Factory for EDA by setting up your environment, enabling monitoring dashboards, and configuring latency analysis to optimize FSx for ONTAP performance for your EDA workloads.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png[One] Log in to Workload Factory

[role="quick-margin-para"]
You'll need to link:../setup/sign-up-and-log-in.html[sign up and log in] to the NetApp Console.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png[Two] Add credentials and permissions for the EDA workload

[role="quick-margin-para"]
link:../fsx-storage/add-credentials-fsx.html[Add credentials to an account manually] that includes selecting the EDA workload capability, and link:../fsx-storage/permissions-fsx.html[create the IAM policies for the required permissions].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png[Three] Set up your environment to meet EDA requirements

[role="quick-margin-para"]
You'll need a deployed and discovered FSx for ONTAP file system that contains at least one volume that has been configured as an NFS share.

[role="quick-margin-para"]
link:requirements-eda.html[Learn more about EDA requirements^].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png[Four] Enable the Overview dashboard

[role="quick-margin-para"]
Enable the Overview dashboard to monitor the health, capacity, and throughput of your FSx for ONTAP clusters. Accept the consent prompt to allow Workload Factory to begin collecting CloudWatch metrics.

[role="quick-margin-para"]
link:task-activate-overview-dashboard-eda.html[Learn how to activate the Overview dashboard^].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png[Five] Configure the Projects dashboard

[role="quick-margin-para"]
Configure the Projects dashboard to monitor system health, performance, and storage usage, enabling you to optimize your EDA environment effectively.

[role="quick-margin-para"]
link:task-configure-project-dashboard-eda.html[Learn how to configure the Projects dashboard^].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png[Six] Configure FSx for ONTAP latency analysis

[role="quick-margin-para"]
Set up latency thresholds to proactively identify and resolve performance issues before they impact simulation run time. Configure warning and critical alerts, set up email or SNS notifications to receive real-time alerts, leverage automated basic analysis, and optionally use AI analysis for complex scenarios.

[role="quick-margin-para"]
link:task-configure-latency-monitoring-eda.html[Learn how to configure latency monitoring^]. After events are detected, you can link:task-analyze-latency-trends-eda.html[analyze latency trends^] using the interactive graph.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-7.png[Seven] Integrate with other services

[role="quick-margin-para"]
Integrate EDA with other services such as a service portal or Perforce Helix Core using the Workload Factory REST API.

[role="quick-margin-para"]
link:integrate-perforce-eda.html[Learn how to integrate EDA with Perforce^].
