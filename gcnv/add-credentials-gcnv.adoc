= Add Google Cloud NetApp Volumes credentials to NetApp Workload Factory
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
Add and manage your cloud provider credentials so that NetApp Workload Factory has the permissions that it needs to deploy and manage resources in your cloud provider accounts. 

== Overview

You can add Google Cloud NetApp Volumes credentials from the Credentials page in NetApp console. The console provides guided setup instructions and a documentation link so you can complete the required Google Cloud configuration and then return to finish adding the credentials.

Use this workflow to grant Workload Factory the permissions that it needs to discover, analyze, and manage resources in your Google Cloud environment.

There are three parts to creating the credentials:

* Step 1: Select the permissions level that you want to grant to Workload Factory.
* Step 2: Create and validate a Google Cloud service account, and then select the Google Cloud project to manage.
* Step 3: Enter a credentials name and add the credentials.

.Before you begin

You'll need to have credentials to log in to your Google Cloud account.

.Steps

. Log in to the https://console.netapp.com/[NetApp console^].
. From the menu, select *Workloads* > *Administration* > *Credentials*.
. On the Credentials page, select *Add credentials*.
. Select *Google Cloud NetApp Volumes* as the cloud provider.
. On the Add Google Cloud NetApp Volumes credentials page, complete each section under *Permissions configuration*.

=== Step 1: Create permission policies

.Steps

. Under *Create permission policies*, *View, plan, and analyze* is selected by default. This permission policy allows you to view Google Cloud NetApp Volumes storage pools, learn about system health, get the well-architected analysis for your systems, and explore savings.
. Optional: Select *Operations and remediation* If you also want Workload Factory to manage Google Cloud NetApp Volumes resources and fix configuration issues.
. Review the setup instructions at link:https://docs.netapp.com/us-en/storage-management-google-cloud-netapp-volumes/task-set-up-gcnv.html#set-up-a-service-account[Set up Google Cloud NetApp Volumes^] before you continue.

=== Step 2: Create the Google Cloud service account

.Steps

. Expand *Set up your Google Cloud environment*.
. Complete the steps 1-5 that are displayed to create a Google Cloud service account.
. Copy the service account email address.
. Return to Workload Factory, paste the email address into the *GCP service account* field, and select *Validate credentials*.
. After validation is complete, from the *Projects* dropdown, select the Google Cloud project that you want Workload Factory to manage.
NOTE: The Projects list is unavailable until the service account credentials are verified.

=== Step 3: Enter the credentials name

.Steps

. Expand *Credentials name*.
. In the *Name* field, enter a credentials name using only alphanumeric characters. Special characters and spaces are not allowed.
. Select *Add*.

.Result

The Google Cloud NetApp Volumes credentials are added to your account and are available for supported Workload Factory operations.
