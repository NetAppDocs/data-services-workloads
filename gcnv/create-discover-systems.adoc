= Add a Google Cloud NetApp Volumes system in NetApp Console
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ../media/

[.lead]
Add a Google Cloud NetApp Volumes system so that you can manage its storage pools and volumes from the NetApp Console.

== Add a system
Register the project you want to manage so that Workload Factory includes its storage pools in every region.

.Before you begin
Add credentials for your Google Cloud NetApp Volumes project in Workload Factory. link:add-credentials.html[Learn how to add credentials].

.Steps
. From the NetApp Console menu, select *Storage* > *Management* > Systems, and then select *Add system* > *Google Cloud Platform*.
. Under *Google Cloud NetApp Volumes*, select *Discover*.
. Enter a name for the system.
. Select the credentials for the system.
. Optionally, select a region. If you don't select a region, the system covers all regions.
+
NOTE: The region does not limit discovery. Workload Factory discovers storage pools in every region for the credentials. The region you select sets what the system shows on the canvas and what Compliance and DRaaS use.
. Click *Discover*.

.Result
The NetApp Console shows the system on the Systems page. You can add any number of systems for the same credentials.
