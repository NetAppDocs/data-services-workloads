= Edit the S3 access points for an FSx for ONTAP volume in NetApp Console
:icons: font
:imagesdir: ./media/

[.lead]
Update S3 access point details and manage tags for an FSx for ONTAP volume in NetApp Console. 

You can also enable or disable the *Inventory table* for the access point. The inventory table generates metadata for all objects accessible to the S3 access point and incurs AWS S3 request costs. Refer to link:https://aws.amazon.com/s3/pricing/[Amazon S3 pricing documentation^] for more information.

.Steps
. Log in to the link:https://console.netapp.com[NetApp Console^].
. Select the menu image:workloads-menu-icon.png[The hamburger menu icon is used to navigate to Workloads, the menu item for Workload Factory], *Workloads* > *Volumes explorer*.
. Select the actions menu for the volume you want to edit S3 access points for, then select *Advanced actions*, and then *Manage S3 access points*.
. From the *Manage S3 access points* screen, select the actions menu and then select *Edit access point*.
. Make updates and then select *Apply*. 
+
To set up the infrastructure for the journal table feature, you must select *Internet* as the network configuration for the S3 access point. link:setup-journal-table.html[Learn how to set up the Journal table infrastructure].
