= Track replication delays in NetApp Workload Factory
:icons: font
:imagesdir: ../media/

[.lead]
Turn on tracking to monitor replication delays across your account. Workload Factory alerts you when delays go beyond a set threshold. By default, the threshold is 150% of the replication interval to allow normal transfer time and reduce false alarms. You can adjust the threshold to match your RPO and get notifications when delays exceed it. You can also export the data to a CSV file for further analysis.

.Steps
. Log in to the link:https://console.netapp.com[NetApp Console^].
. Select the menu image:workloads-menu-icon.png[The hamburger menu icon is used to navigate to Workloads, the menu item for Workload Factory], *Workloads* > *Storage* > *FSx for ONTAP*. 
. From *FSx for ONTAP*, select the actions menu of the file system to update and then select *Manage*.  
. From the file system overview, select the *Replication relationships* tab. 
. Select *Enable tracking*.
. In the Enable replication lag history dialog, select *Enable*. 
. Back in the Replication lag history tile, select *Customize threshold* to set your preferred threshold.
. In the Customize lag time threshold dialog, enter the threshold in hours and minutes. 
. Optionally, select *Enable lag time notifications* to receive notifications when replication lags 
exceed the threshold. 
+
Notifications come in an email and include:
+
* Source file system
* Source volume
* Target file system
* Target volume
* Lag time threshold that was exceeded
* Link to the replication relationship

. Select *Apply*.
